# AEIOU Local Compressor v2.1 JSON

## 改动范围

v2.1 没有替换 AEIOU 五维架构，只增加结构化 JSON 入口：

1. 每条 JSON 记录作为一个原始关系单位。
2. 数值字段名通过 SHA-256 得到固定五维方向。
3. 数值使用确定性的有界变换参与该方向载荷。
4. 字符串、布尔值与空值按固定事件载入五维坐标。
5. 后续代表记录选择、同步循环、逐对细化及全局轨迹补入沿用 v2.0。

## 为什么默认忽略 frame_id 与 timestamp

它们是顺序标识，不是画面状态。若让连续增长的编号进入载荷，会让编号变化压过画面特征变化。
忽略只发生在向量计算阶段，原始字段仍完整保留在输出 JSON 记录中。

## 支持结构

- 顶层 JSON 数组
- 顶层对象中的 `frames` / `records` / `events` / `items` / `data` 数组
- JSONL / NDJSON

## 边界

该适配器处理的是已经结构化的帧特征数据，不直接执行视频解码、目标识别或动作识别。
